# My Notes App

A simple and responsive notes application built with React and Vite.

## Features

* Add new notes
* Edit existing notes
* Delete notes
* Search notes
* Cancel editing
* Save notes using browser local storage
* Responsive design for different screen sizes

## Technologies Used

* React
* JavaScript
* Vite
* CSS
* Local Storage

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local development URL shown in the terminal.

## Project Purpose

This project was created as part of my web development learning journey to practice React, state management, event handling, local storage, and building an interactive user interface.
